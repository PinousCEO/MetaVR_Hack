Living AI Partner — 기능 확인 결과와 테스트 방법

2026-11-16 17:20 KST 기준 · Meta VR Start Developer Competition 2026 (Productivity) · 캐릭터: Momo
먼저 알아두실 것. 아래 결과는 전부 PC + 데스크톱 MR 시뮬레이터에서 확인한 것입니다. Quest 실기기에서는 아무것도 실행해 보지 못했습니다(헤드셋 미연결). 실제 손 추적, 패스스루로 본 모습, 기기에서의 지연은 미검증입니다.

1. 질문하신 내용에 대한 답

물어보신 시점에는 다 된 상태가 아니었습니다. 그때 있던 것은 "가리킨 창을 캡처해 코드 수정 제안을 주는 기능"뿐이었고, 수정본 PNG/PDF 생성과 PDF/PNG 파일 읽기는 없었습니다. 그래서 새로 구현했고, 실제 OpenAI 호출로 돌려 확인했습니다.

요청하신 것상태확인한 방법과 결과
내가 가리키는 화면을 인식해서 확인됨가리킨 창으로 Momo가 들어가 그 창만 캡처해 봄. 요청 후 49초(들어가는 이동 포함)에 메모 5개
나에게 피드백됨가장 중요한 점을 바로 말로 전달하고, 메모는 카드로 방에 가지고 나옴. 일부러 넣은 결함(제목 오타, 흐린 글씨, 안 보이는 입력칸, "Sumbit", 크기 다른 버튼)을 짚음
실제 수정본 PNG / PDF 생성됨feedback.png(번호 표시본), revised.png(고쳐 그린 수정본), review.pdf(3쪽) 저장. 문서는 revised.pdf(고친 글)
컴퓨터에 들어왔을 때 PDF 파일 읽기됨16~20초. 예산·출시일 같은 사실과 심어둔 날짜 모순을 찾음. notes.pdf + revised.pdf 저장
PNG 파일 읽기됨35초. 화면 리뷰와 같은 파일 3개 생성
읽은 파일에 대해 다시 묻기됨"방금 읽은 파일에서 출시일이 언제야?" → "2026-12-03이야." (한국어·영어)
테니스 게임됨시작 → 랠리(최장 17타) → 5점 종료 → 중간 정지 → 책상 복귀. 검증 5항목을 두 번 통과

2. 화면 리뷰와 수정본

동작 순서

  • 창을 가리키며 "이거 어때? 피드백 줘"라고 말하거나 손 메뉴 Look을 누릅니다.
  • Momo가 그 창으로 들어가 창을 캡처하고, 핵심 피드백을 바로 말합니다.
  • 약 30초 뒤 PC의 문서\LivingAIPartner\Reviews\<시간>-<창 이름>\에 파일이 저장됩니다.
  • Momo를 부르면 메모를 카드로 들고 나옵니다. 카드의 Open이나 패널의 Preview는 PC에서 PDF를 엽니다.

저장되는 파일

파일내용
feedback.png캡처 위에 번호 표시, 옆에 메모
revised.png제안을 반영해 이미지 모델이 다시 그린 수정본
review.pdf요약, 표시본, 피드백(문제/제안), 수정본, 원본
original.png, review.json원본 캡처와 원자료

3. 파일 읽기 (PDF · 그림 · 텍스트)

  • 지원 형식: PDF, PNG / JPG / WebP / BMP / GIF, TXT / MD (24MB 이하).
  • 어떤 파일인지 알려주는 방법 세 가지:
    • 파일이 열린 창을 가리키거나 그 창 안에 Momo가 있을 때 "이 파일 읽어줘" — 창 제목의 파일 이름으로 찾습니다.
    • 파일 탐색기에서 파일을 선택하고 그 창을 가리킵니다.
    • 트레이 아이콘 > Show a file to the partner…
  • 문서는 notes.pdf(요약·핵심·자세한 내용·고칠 점)와 revised.pdf(고친 글)가 저장됩니다. 원문에 없는 사실은 지어내지 않고 [date?]처럼 빈칸으로 표시합니다.
  • 그림 파일은 화면 리뷰와 똑같이 처리됩니다(파일 3개).
  • 읽은 뒤에는 그 파일에 대해 물어볼 수 있습니다.

4. 테니스

모니터 유리가 네트입니다. Momo는 모니터 안의 코트에서 치고, 공이 유리를 통과해 방으로 나오면 편 손바닥으로 받아칩니다. 코트는 머리 위치를 기준으로 원근을 계산해 모니터 전체에 그립니다.

  • 시작: 손 메뉴 Tennis 또는 "테니스 하자". Momo가 책상에 있으면 스스로 모니터로 들어간 뒤 시작합니다.
  • Momo가 서브합니다. 공이 나오면 손바닥으로 맞히면 되고, 손을 옆으로 움직이며 치면 방향이 바뀝니다.
  • 못 받은 공이 책상에 두 번 튀거나 지나가면 Momo 점수, Momo가 놓치면 내 점수. 5점 선취.
  • 끝내기: 같은 버튼(Stop) 또는 "테니스 그만".

5. 직접 테스트하는 방법

A. 헤드셋 없이 PC만으로 — 파일 읽기와 리뷰

.\tools\Make-ReviewSamples.ps1          # 결함을 넣은 샘플 화면(PNG)과 회의록(PDF) 생성
.\tools\Start-Dev.ps1 -LoopbackOnly     # 호스트 + PC 캐릭터 실행
$ctl = "Companion\LivingPartner.Ctl\bin\Release\net8.0\lpctl.exe"

& $ctl readfile samples\review\meeting-notes.pdf "이 파일 읽고 고칠 점 알려줘"
& $ctl utter "방금 읽은 파일에서 예산이 얼마야?"
& $ctl readfile samples\review\signup-form.png "이 디자인 피드백 줘"
& $ctl tasks                           # 진행 상태, 메모, 저장된 파일 경로

본인 파일은 경로만 바꾸면 됩니다. 헤드셋이 없으면 완료 시 PDF가 자동으로 열리도록 되어 있습니다. 끝낼 때는 .\tools\Stop-Dev.ps1.

B. 시뮬레이터로 전체 흐름 자동 확인

.\tools\Start-Dev.ps1 -Sim -LoopbackOnly
.\tools\Run-ReviewChecks.ps1     # 리뷰·읽기 5항목 → artifacts\review-checks.txt (API 비용 몇 센트)
.\tools\Run-TennisChecks.ps1     # 테니스 5항목   → artifacts\tennis-checks.txt

테니스만 눈으로 보려면 시뮬레이터를 띄운 뒤:

& $ctl debug simHand 0 0 0 tennis    # 스크립트 손이 공을 받아침
& $ctl tennis start                  # 끝낼 때: & $ctl tennis stop

C. 헤드셋에서

하는 것일어나는 일
창을 가리키며 "이거 어때? 피드백 줘" / 손 메뉴 Look들어가서 보고, 말로 알려주고, 파일 저장
파일이 열린 창을 가리키며 "이 파일 읽어줘"파일을 읽고 요약, 메모와 수정본 저장
"돌아와" / 손 메뉴 Return메모 카드를 들고 나옴
손 메뉴 Tennis / "테니스 하자"코트가 열리고 서브

6. 한계와 확인하지 못한 것

  • 수정본 그림은 시안입니다. 이미지 모델이 다시 그린 것이라, 검증 실행에서 제목·버튼 오타는 고쳤지만 라벨 오타 두 개("Email adress", "Confirm pasword")는 그대로 남겼고 비율도 원본과 조금 다릅니다.
  • 표시 위치는 대략적입니다. 번호 박스가 요소에서 조금 어긋날 수 있습니다.
  • 생성된 PDF는 글자 선택이 안 됩니다. 쪽을 그림으로 넣은 형식입니다.
  • 후속 질문은 메모 기반입니다. 읽을 때 적어둔 내용으로 답하고, 파일을 다시 읽지는 않습니다.
  • 코드 프로젝트가 연결된 창은 예전처럼 코드 분석(제안 카드 → 브랜치 수정)으로 갑니다.
  • 실행해 보지 못한 것: 탐색기에서 선택한 파일 읽기, 트레이 메뉴 두 항목, 헤드셋 없을 때 PDF 자동 열기, 카드의 Open/Preview로 PDF 열기, 큰 PDF·스캔 PDF.
  • 테니스: 사용자 손은 시뮬레이터가 공 경로에 놓아주는 스크립트 손이었습니다. 실제 손으로 잘 맞는지, 공이 실제 유리를 지날 때 하나로 보이는지는 헤드셋이 있어야 알 수 있습니다. 소리는 없고, 경기 중에는 코트가 그 모니터 전체를 덮습니다(클릭은 통과).
  • 이번 빌드에서 다시 돌리지 않은 검증: 음성, 복구, 창 추종, 페어링, 코드 분석 하네스.

7. 그 밖의 상태

  • 회귀 검증 통과: MR 기능 4/4, 포털 왕복 3회, 포인팅 27지점 최대 오차 0.0px, 단위 테스트 306개.
  • 빌드: Windows 클라이언트, 호스트 배포본, Quest APK(50.6MB, 미설치).
  • 비용: 리뷰 1회에 OpenAI 비용 몇 센트(시각 모델 1회 + 이미지 1장). 화면 캡처와 파일은 요청했을 때만, 본인 키로 OpenAI에 전송됩니다.
  • OpenAI 키는 저장소·스크립트·로그 어디에도 들어 있지 않습니다. 대회가 끝나면 키를 교체하시기를 권합니다.
  • 커밋·푸시는 하지 않았습니다.
