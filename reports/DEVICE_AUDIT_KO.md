# 밤비 · Quest, Windows, MacBook/TV 점검

## 최신 게임 구성

- **악마의 문은 1인 PC 게임이다.** 여섯 종류의 3D 모델은 후드 안쪽을 어둡게 파고 작은 호박색 눈만 남겼다. Windows 실행본에 키보드와 마우스 입력을 보내 강화 12회를 거쳐 보스를 쓰러뜨렸다. 최종 기록은 처치 196마리, 4,784점이었고 곧바로 새 게임을 시작할 수 있었다. [플레이 녹화](DEMON_GATE_GAMEPLAY.mp4) · [강화 선택](DEMON_GATE_CHARMS.jpg) · [보스전](DEMON_GATE_SOLO.jpg)
- **오목은 두 사람이 같은 TV를 보고 하는 게임이다.** 양쪽 돌통은 밤비 원화의 보닛 주름과 크림색 칼라, 살구색 단추를 본떠 만들었다. 착용자가 TV의 교차점을 가리키고 오른손을 핀치하면 흑돌이 놓인다. 백돌 차례에는 착용자가 상대의 검지와 TV를 함께 본다. TV에 후보 칸이 먼저 표시되고, 같은 칸을 0.9초 유지하면 백돌이 놓인다. [상대가 가리킨 후보 칸](GOMOKU_AIM.png) · [흑백 착수 화면](GOMOKU_PLAY.png)
- **상대 손 인식**은 Quest가 페어링한 컴퓨터에 보내는 카메라 프레임과 오프라인 손 추적 모델을 사용한다. 시야를 벗어난 손, 주먹, 여러 사람이 동시에 가리키는 경우와 착용자 자신의 손은 착수 대상에서 제외한다. 모의 Quest 연결로 착용자의 입력과 검지를 편 손의 시험 사진을 보내 실제 TV용 게임에서 흑백 8수가 번갈아 놓이는 것을 확인했다. 두 사람이 실제 TV 앞에서 가리켰을 때의 오차와 속도는 현장 확인 항목이다.
- **테니스와 골키퍼**는 화면 안팎을 오가는 공과 손의 충돌을 점검했다. Mac 호스트와 화면은 자동 테스트했고, 실물 MacBook과 HDMI TV 조합은 현장 확인 항목이다.

### 배포본 확인

Windows용 단독 게임 실행기로 브라우저에서 플레이한 후 마지막 탭을 닫자 6초 뒤 서비스가 종료됐다. Windows 배포본의 오목판·손 인식 파일 17개와 악마 모델·메뉴 그림이 소스와 바이트 단위로 일치했다. .NET 테스트 2,028개와 손가락 조준 테스트 9개가 통과했다.

새 악마 모델을 포함해 Windows 플레이어와 Quest APK를 빌드했다. Apple Silicon과 Intel용 Mac ZIP에 같은 모델과 오목판, 같은 Quest APK가 들어 있는지 확인했다. APK의 SHA-256은 `10813d07d334bc9036f26eecd8ad47f402f9e5f2471fb419c604ef0c78a85e84`이다. 이전 버전은 Quest 3에서 설치를 확인했고 카메라 사진의 상하 방향과 TV 좌표 변환은 Unity에서 검증했다.

## 배포본 점검

- 전체 .NET 테스트 2,009개가 통과했다. Windows 최종 플레이어로 골키퍼·슈팅·서바이벌을 실행해 화면을 캡처했다. 세 게임은 공유 엔진에서 각각 2분간 화면 요소를 누락하지 않고 그리기 한도(160개)를 지켰다. [플레이 화면 네 장](GAMEPLAY_20261118.jpg)
- Windows 빌드와 Quest 빌드가 오류 0개로 끝났다. 배포한 Windows 호스트와 클라이언트의 DLL을 최종 빌드와 대조했다. 컴패니언 창이 열렸고 모니터 세 대가 표시됐다.
- Quest 3에 최종 APK를 기존 데이터를 유지해 설치했다. 14시 54분 설치 직후 기기 안의 APK와 두 Mac ZIP에 포함한 APK의 SHA-256이 모두 `e6077511f579698548ed43f35f3b21be925725ac4ef51f2c4f2635071c198576`으로 일치했다. 설치 직후 헤드셋은 잠금 화면에 있었다. 위의 실물 화면 인식 결과는 같은 날 앞선 실행에서 확인했다.

## 실제 기기에서 남은 확인

Apple Silicon과 Intel 각각의 실행 파일, 실행 권한, 서명 해시와 ZIP을 검사했다. MacBook에서의 최초 권한 승인, HDMI 출력 및 두 사람이 거실에서 여섯 번을 완주하는 과정은 아직 실기 확인이 필요하다. Mac 배포본은 Apple 공증 전 개발 빌드다.

생성 기능 자동 검사는 테스트용 모델 응답을 사용했다. 조사 보고서, 자유 주제 이미지·3D 제작을 실제 서비스로 실행할 때는 Mac에 사용자 본인의 API 키가 필요하다. TV 랠리의 상대방 동작은 Quest에서 처리하며 TV에는 게임 상태와 점수가 표시된다.
