# MacBook에서 밤비와 TV 연결하기

혼자 **악마의 문**을 하려면 Mac 패키지에서 **Start-Bambi.command → 악마의 문 · 혼자 플레이**를 여세요. 헤드셋 없이 마우스와 키보드로 바로 시작할 수 있습니다.

두 사람이 TV 오목을 하거나 Quest에서 밤비를 TV로 보내려면 아래 순서로 연결하세요. 배포용 ZIP에는 Mac 실행 환경, 한국어 음성 인식 모델, Quest 앱이 들어 있습니다. USB 디버깅을 허용한 Quest를 연결하고 Start-Bambi.command를 열면, 게임이 닫혀 있는 동안 새 버전을 미리 설치합니다. 처음 USB를 설정하는 방법은 아래 **Quest 앱 설치 또는 업데이트**에 있습니다.

1. **MacBook과 TV를 연결합니다.** HDMI 포트가 있으면 HDMI 케이블을, USB-C 포트만 있으면 영상 출력을 지원하는 USB-C–HDMI 어댑터를 사용하세요. TV에서 해당 HDMI 입력을 선택하세요. Mac의 **시스템 설정 → 디스플레이**에서 TV를 확장 디스플레이로 설정하면 MacBook의 다른 화면도 쓸 수 있습니다. [Apple의 TV 연결 안내](https://support.apple.com/guide/mac-help/mchlp1206/mac)
2. **Mac 패키지를 엽니다.** Apple 메뉴 → **이 Mac에 관하여**에서 칩을 확인하세요. Apple M 시리즈는 `LivingPartner-Mac-arm64.zip`, Intel은 `LivingPartner-Mac-x64.zip`을 사용합니다. 압축을 풀고 **Bambi TV → Start-Bambi.command**를 여세요. 터미널이 열리고 기본 브라우저에 **밤비의 TV**가 나타납니다. 터미널은 플레이하는 동안 열어 두세요. 배포본은 Apple 개발자 서명과 공증을 받지 않은 개발 빌드입니다.
3. **TV와 Quest를 페어링합니다.** Quest와 Mac을 같은 가정용 네트워크에 연결하고 Quest 앱을 여세요. 브라우저 창을 TV로 옮기고 **이 화면을 TV로 사용**을 누르세요. Quest 숫자 키패드에 TV에 표시된 여섯 자리 번호를 입력합니다. 성공하면 TV에 헤드셋 이름이 뜹니다. macOS가 로컬 네트워크나 수신 연결 권한을 물으면 이 컴패니언에 허용하세요. 게스트 Wi-Fi처럼 기기끼리 연결을 차단하는 네트워크에서는 검색이 실패합니다.
4. **실제 TV의 위치를 맞춥니다.** 헤드셋을 쓴 채 TV를 보고 안내를 따르세요. 필요하면 Mac의 **TV 위치 확인**을 누르세요. TV가 잠깐 색을 표시하면서 화면을 맞춥니다. TV 크기를 직접 정하려면 전체 화면을 종료하고 **화면 크기 직접 입력**에 대각선 인치를 입력한 뒤 다시 시작하세요.
5. **밤비를 보내고 부릅니다.** “밤비야, TV로 들어가”와 “밤비야, 방으로 돌아와”로 양방향 이동을 시킬 수 있습니다. TV 설정에도 같은 버튼이 있습니다. “밤비야”라고 부르면 밤비가 말풍선으로 대답합니다. **밤비의 대답을 소리로 듣기**를 켜면 밤비가 있는 쪽에서도 소리를 들을 수 있습니다. 마이크 사용 권한은 Quest에서 허용하세요. TV 설정의 입력창으로도 같은 명령을 보낼 수 있습니다.

## 악마의 문 · Mac에서 혼자 플레이

MacBook에서 플레이하거나 브라우저 창을 HDMI TV로 옮기세요. 마우스로 조준하고 왼쪽 버튼을 누르고 있으면 연속 발사합니다. A·D 또는 좌우 방향키로 이동하세요. 레벨이 오르면 부적을 고르고 마지막 보스 가시 왕을 막으세요.

## 둘이서 TV 오목

1. 위의 연결 절차대로 실제 TV의 위치를 맞춘 다음, TV 설정에서 **둘이서 오목 → 게임 시작**을 누르거나 헤드셋에서 “밤비야, 오목 하자”라고 말하세요. 두 사람 모두 같은 TV에 표시되는 15줄 오목판을 봅니다.
2. **흑은 헤드셋 착용자**입니다. 빈 교차점을 오른손 검지로 가리키고 검지와 엄지를 맞대어 돌을 놓으세요. **백은 맞은편 사람**입니다. 착용자가 상대의 손과 TV를 헤드셋으로 바라보고, 상대가 검지를 펴서 실제 TV의 빈 교차점을 가리킵니다. TV에 뜬 후보 표시가 원하는 곳에 있을 때 **0.9초 이상 그대로 유지**하면 백돌이 놓입니다.
3. 카메라 권한과 착용자의 확인을 마친 후 백 차례에 Quest 카메라가 상대 손을 읽습니다. 프레임은 같은 네트워크의 Mac으로 전송되며 추론과 판정은 Mac에서 실행됩니다. 카메라 영상은 저장하지 않습니다. Quest 3 또는 3S의 카메라가 가려졌거나 손이 보이지 않으면 백돌은 놓이지 않습니다.
4. 가로, 세로, 대각선 중 한 줄로 다섯 개 이상을 먼저 이으면 승리합니다. TV에서 **다시 두기**로 새 판을 시작하거나 **대국 종료**를 누르세요.

## Quest에서 즐기는 게임

TV 설정의 게임 목록에서 하나를 고르고 **게임 시작**을 누르거나, Quest에서 “밤비야, 테니스 하자”처럼 게임 이름을 말하세요. TV 위치가 맞춰져 있으면 테니스와 골키퍼는 밤비가 TV 안으로 들어간 뒤 시작합니다. 옆에 있는 사람도 TV에서 경기와 점수를 볼 수 있습니다.

- **골키퍼** — 밤비가 TV 안에서 찬 3D 축구공이 화면 밖 방으로 날아옵니다. 헤드셋을 쓴 사람이 손으로 막으면 공이 TV 안으로 돌아갑니다. 다섯 번의 슛 중 몇 개를 막았는지 겨룹니다.
- **테니스** — 밤비의 서브가 TV 밖으로 나오면 손으로 라켓을 휘둘러 받아치세요. TV와 Quest가 같은 공의 궤적과 점수를 표시합니다.
- **악마의 문 · 선택형 MR 모드** — Quest 가방의 게임 메뉴에서 시작하세요. TV에 나타난 3D 악마가 화면을 넘어 방으로 들어옵니다. 오른손 검지로 조준하고 왼손 손바닥으로 막으세요. 레벨이 오르면 헤드셋에서 세 가지 강화 카드 중 하나를 고릅니다.

TV의 **게임 종료**를 누르거나 “밤비야, 게임 그만”이라고 말하면 기본 화면으로 돌아옵니다.

## Quest 앱 설치 또는 업데이트

1. 휴대폰의 Meta Horizon 앱에서 연결된 Quest의 **개발자 모드**를 켜세요. 처음 사용하는 계정은 Meta 개발자 등록과 인증이 필요합니다. [Meta 기기 설정 안내](https://developers.meta.com/horizon/documentation/native/android/mobile-device-setup/)
2. Mac에 ADB가 없다면 **Download SDK Platform-Tools for Mac**을 선택하고 다운로드 폴더에 압축을 푸세요. 설치 도구는 `~/Downloads/platform-tools/adb`, 기존 Android SDK 및 PATH에 있는 ADB를 찾습니다. [Google Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools#downloads)
3. 데이터를 전송할 수 있는 USB 케이블로 Quest 하나를 Mac에 연결하고 **Bambi TV → Install-Quest.command**를 여세요. 헤드셋에서 이 Mac의 **USB 디버깅 허용**을 승인한 뒤, 도구가 이미 종료됐다면 다시 여세요. 도구는 배포본의 `Quest/LivingAIPartner.apk`를 설치합니다. 업데이트에는 기존 앱 데이터를 유지하는 `adb install -r`를 사용합니다.
4. 설치 완료가 뜨면 Quest의 앱 라이브러리에서 **알 수 없는 출처 → Living AI Partner**를 여세요. 설치용 USB 케이블을 뽑아도 같은 Wi-Fi로 Mac에 연결됩니다. 카메라 및 마이크 권한은 해당 기능을 처음 쓸 때 헤드셋에서 선택하세요.

## 연결 상태와 데이터

- Mac 브라우저의 기본 주소는 `http://127.0.0.1:47610`입니다. 브라우저 화면과 페어링 코드는 Mac에서만 열 수 있습니다. Quest는 같은 네트워크의 UDP 47611에서 Mac을 찾고 TCP 47610으로 연결합니다.
- 다운로드한 개발 빌드를 처음 열 때 macOS가 출처 확인을 요구할 수 있습니다. 직접 받은 패키지와 체크섬을 확인한 경우에는 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 해당 파일의 실행을 승인할 수 있습니다. [Apple의 첫 실행 안내](https://support.apple.com/ko-kr/102445)
- 시작 후 화면 확인이 끝나면 TV 설정을 접을 수 있습니다. 다시 열 때는 **TV 설정**을 누르세요. 터미널에서 **Control-C**를 누르면 Mac 호스트가 종료됩니다.
- 음성 인식은 함께 배포한 다국어 Whisper 모델로 Mac에서 처리합니다. 인식한 명령은 TV 이동, 화면 보정, 게임, 작업 요청에 연결됩니다. 작업 종류에 따라 별도의 생성 서비스 설정이 필요할 수 있습니다. [Whisper.net](https://github.com/sandrohanea/whisper.net) · [모델](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-small-q5_1.bin)
- Mac은 브라우저 전체 화면을 밤비의 TV로 사용합니다. Windows의 바탕화면 캐릭터 오버레이, 임의의 응용 프로그램 창 조작 및 Windows 마켓플레이스는 Mac 배포 범위 밖입니다.

## 작업 대기줄과 생성

“밤비야, 해달 아이콘 PNG 만들어 줘”, “밤비야, 고래에 대해 조사해서 PDF로 만들어 줘”라고 말하면 TV 아래쪽 **작업** 버튼에서 진행 상황과 완성된 파일을 볼 수 있습니다. 자료 조사, PDF·PNG 생성과 자유 형태의 3D 제작에는 OpenAI API 키가 필요합니다. Mac **키체인 접근**에서 일반 암호 항목의 서비스 이름을 `LivingPartner.OpenAI`, 암호를 API 키로 설정하거나 실행 프로세스에 `OPENAI_API_KEY`를 설정하세요.

새 게임의 규칙과 코드는 Claude Fable 5.2가 작성합니다. Mac 키체인의 일반 암호 항목 `LivingPartner.Anthropic`에 Anthropic API 키를 저장하거나, 컴패니언 프로세스에 `ANTHROPIC_API_KEY`를 설정하고 다시 실행하세요. 모델 접근 권한과 인터넷 연결이 필요합니다. 설치된 게임 플레이, 음성 인식, “기본 골키퍼 게임 만들어 줘”처럼 내장 레시피를 지정하는 요청은 키 없이 사용할 수 있습니다. [Claude Fable 5.2 모델 정보](https://platform.claude.com/docs/en/models/fable-5-2/overview)

“이 아이콘 다시 그려 줘”라는 요청은 Quest에서 가리킨 Mac 화면의 작은 영역을 사용합니다. macOS가 화면 기록 권한을 물으면 해당 기능을 쓸 때 허용하세요.

Quest에 물건을 들어 보이며 “밤비야, 이거 만들어 줘”라고 하면 카메라로 한 장을 찍어 3D 모델을 만듭니다. 이 기능은 사용자가 설정한 생성 서비스에 그 사진을 전송합니다. 완성한 모델은 가방에서 열거나 Mac 작업 대기줄의 GLB 파일로 다운로드할 수 있습니다.

## 개발 검증

저장소 루트에서 .NET 8 SDK로 `dotnet build Companion/LivingPartner.Mac -c Release`를 실행할 수 있습니다. Node.js 22 이상이 있으면 `node Companion/LivingPartner.Mac/test/protocol.mjs`가 별도 임시 포트에서 Quest 프로토콜로 페어링, 화면 보정, 왕복 이동, 게임 연결, 이름 호출을 검사합니다. 실제 마이크 입력 파일을 포함하려면 테스트에 DLL 경로, Whisper 모델 경로, 한국어 이름 호출이 포함된 PCM16 모노 WAV 경로를 차례로 전달하세요.

로컬 Chrome 또는 Chromium이 있으면 `node Companion/LivingPartner.Mac/test/webgl.mjs`로 별도 헤드리스 브라우저에서 실제 3D 게임 화면을 검사합니다. 여섯 악마의 메시, 강화 카드 세 장, 두 종류의 공, 그래픽 컨텍스트가 끊겼다가 복구될 때의 동작을 확인합니다. 브라우저가 기본 경로에 없으면 `CHROME_PATH`를 지정하세요. 테스트에 DLL 경로와 캡처를 저장할 폴더를 차례로 전달하면 각 게임 화면을 PNG로 저장합니다.

Python 3.11 이상에서 `python tools/Build-Mac.py`를 실행하면 모델 SHA-256을 확인한 뒤 두 아키텍처의 독립 실행 ZIP을 `dist/LivingPartner-Mac`에 만듭니다. 기본 경로 `dist/LivingAIPartner-Quest/LivingAIPartner.apk`에 Quest 빌드가 있으면 함께 담습니다. 다른 APK는 `--quest-apk 경로`로 지정하세요. 패키지 생성에는 인터넷 접속이 필요합니다. 실제 Mac과 TV에서 케이블, macOS의 권한 창, Quest 카메라 보정과 게임 타이밍을 확인할 수 있습니다.
